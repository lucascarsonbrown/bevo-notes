# Bevo Notes - Chrome Extension

AI-powered lecture note generator for UT Austin's Lecture Capture system.

**Notes are generated on your own computer.** The model runs locally in your browser through WebGPU — your lecture transcripts are never sent to an AI provider, and there is no API key to configure.

## Features

- Extracts lecture transcripts from UT Lectures Online
- Generates structured notes locally with Llama-3.2-1B via WebLLM
- Organizes content by topic, with formulas rendered as MathML
- Dark mode, print/export, and cloud sync to your Bevo Notes dashboard

## Requirements

- **Chrome 124 or newer** (WebGPU in extension contexts)
- A GPU with roughly **1 GB of available graphics memory**. On laptops with integrated graphics this comes out of shared system RAM.
- A Bevo Notes account, so generated notes can sync to your dashboard

The extension checks your hardware before downloading anything. If your device can't run the model it will say so — you can still read, organize, and export existing notes.

## Setup

1. Build the local model bundle from the repo root:
   ```bash
   npm install
   npm run build:extension
   ```
2. Open `chrome://extensions/`, enable **Developer mode**, click **Load unpacked**, and select the `LectureNoteTaker` folder.
3. Log in to the Bevo Notes web app so the extension can sync your notes.

## How to Use

1. **Navigate to a lecture** on [lecturecapture.la.utexas.edu](https://lecturecapture.la.utexas.edu/).
2. **Enable captions** with the CC button, then scrub through the video so caption data loads.
3. **Click the Bevo Notes icon** and press Generate.

**The first run downloads about 880 MB of model weights.** That happens once and is cached by the browser; later lectures start immediately. Generating a full lecture takes several passes and a few minutes, depending on your hardware. You can close the popup — generation continues in the background and the popup reattaches when you reopen it.

## Features in Detail

### AI Note Generation

Notes are generated by **Llama-3.2-1B running locally through WebLLM**, in several passes over the lecture:

- **Topic-based structure** — the transcript is split at the lecturer's natural pauses, so sections follow topic changes rather than arbitrary cut points
- **Mathematics** — formulas are produced as LaTeX and rendered to MathML, so they display as real math rather than plain text
- **Definitions, examples, and key points** are extracted into structured fields
- **Filler removed** — jokes, classroom chatter, and technical interruptions are dropped

Because the model is small enough to run on a laptop, notes are less polished than a large hosted model would produce. That is the trade for keeping the feature free and private.

### What Gets Included in Notes

✅ **Included**: definitions and theorems, formulas, worked examples, key takeaways

❌ **Removed**: filler words, classroom chatter, jokes, technical interruptions, repetition

### Dark Mode

- Toggle between light and dark themes with the moon/sun icon
- Preference is saved automatically
- Works in both the popup and the full notes view

## Troubleshooting

### "Please reload the lecture page and try again"
The content script only loads on a fresh page load, so it will be missing if you installed or reloaded the extension while already on the lecture page. Refresh the page (F5 / Cmd+R) and try again.

### "Generation unavailable on this device"
Your hardware failed the capability check. Common causes:
- Browser is older than Chrome 124, or is Firefox (WebGPU is still off by default on most platforms)
- Graphics driver is blocklisted by Chrome, so no GPU adapter is available
- Not enough graphics memory free for a ~880 MB model

Reading, organizing, and exporting existing notes still work.

### No transcript found
- Make sure captions are enabled (CC button)
- Scrub through the video to force caption data to load
- Some lectures have no captions available

### Generation is very slow
Speed depends heavily on your GPU. A modern discrete or Apple Silicon GPU finishes a lecture in a couple of minutes; older integrated graphics can take considerably longer. The first run also downloads ~880 MB before it can start.

### Notes look wrong or incomplete
A 1B model makes mistakes. If a section came out badly, regenerating may produce a better result. Please check anything you plan to rely on for an exam.

## Privacy & Data

- **Local inference**: lecture transcripts are processed on your own machine and are never sent to an AI provider
- **Your notes**: saved to your Bevo Notes account so they sync across devices, and cached locally in `chrome.storage.local`
- **Model weights**: downloaded once from the WebLLM CDN and cached by your browser
- We don't sell or share your data

## Technical Details

**Built With**:
- Chrome Extension Manifest V3 (offscreen document for long-running generation)
- WebLLM + WebGPU, running Llama-3.2-1B locally
- KaTeX for LaTeX → MathML rendering
- VTT caption parsing with timestamp-aware chunking

**Permissions Used**:
- `activeTab` / `scripting`: read captions from the current lecture page
- `storage` / `unlimitedStorage`: cache notes and model state
- `tabs`: open the full notes view
- `offscreen`: run the model somewhere that survives the popup closing
